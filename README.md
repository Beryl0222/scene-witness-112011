# 电影修复中的缺音台词重建与补录交接

业务交接资料为 UTF-8 JSON，每个文件保存一组记录。全部人名、机构、材料与项目均为虚构。
编号在各自资料中使用。保留原文中的省略、转述、标点和异体字，空字段表示交接中没有填值。

## 交接资料

- `data/scripts.json` 保存id、文稿、场目、角色、原文。录入台本和场记原话。角色栏为文稿写法，文稿可包含说明、转述或删文。

- `data/picture.json` 保存id、剪辑、场目、镜头、声道、开始、结束、听辨、前接。时间为成片版次内毫秒。声音类型和剪接行已经由馆员登记，文字为实际可听转写。

- `data/tracks.json` 保存id、录次、声部、角色、来源、原文、区间、剪辑、用途。可调录音库存目录。各份只提供文字、声部、可用剪辑和馆方批准的声轨用途。

- `data/restoration.json` 保存id、顺序、记录、原文。馆方已给出的修复规则与补录档期记录。时间采用场记登记顺序。

## 阅读与运行

使用 Python 3.11.2 和标准库。在仓库根目录查看资料目录和一条原始记录。测试检查原文读入及资料关系。

```text
python3 -m corpus
python3 -m corpus picture --id S2
python3 -m unittest discover -s tests -v
```
